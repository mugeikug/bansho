デジタル板書　インストールと使い始め

Windows 10 / 11（64 ビット）用。管理者権限は要りません。インターネットにつながっていなくても使えます。

1. インストール

  1. 受け取った Bansho-Setup-（版）.exe をダブルクリックします。
    ZIP で受け取った場合は、先に右クリック →すべて展開で取り出してから実行してください。
  2. 青い画面「Windows によって PC が保護されました」が出たら、詳細情報を押し、現れた実行を押します。
    （配布元の電子署名がないために出る確認です。）
  3. 次へ→インストール→完了と進みます。
ブラウザーでダウンロードしたときに「一般的にダウンロードされていません」などと出た場合は、…（その他）→保存→保持するを選んでください。
「WebView2 ランタイムが入っていない」というメッセージが出た場合は、案内に従って Microsoft のページから入れてください（Windows 11 では通常出ません）。

2. 起動とファイルの開き方

起動するスタートメニューのデジタル板書（入れるときに選べば、デスクトップにもアイコンができます）
板書ファイル（.board）ダブルクリックで開きます。
最初の 1 回だけ「このファイルを開く方法を選んでください」と出ることがあります。そのときはデジタル板書を選び、常に使うを押してください。
PowerPoint（.pptx）右クリック →送る→デジタル板書。または板書の開く（Ctrl+O）から選びます。
Windows 11 では「送る」は右クリック →その他のオプションを確認の中にあります。

3. 授業で使う

  • プロジェクターに映す：プロジェクターをつないで Windows キー + P →拡張にしてから、提示画面を開く（F5）を押すと、プロジェクター側に全画面で表示されます。手元の画面で書いた内容がそのまま映ります。
  • PDF にする：PDF出力・印刷（Ctrl+P）を押すと、保存先を聞かれ、1 ページずつの PDF がそのまま保存されます（プリンターを選ぶ必要はありません）。
  • 保存：上書き保存（Ctrl+S）。保存せずに閉じようとすると確認が出ます。

4. 新しい版への更新・アンインストール

  • 更新：新しいインストーラーをそのまま実行してください（上書きされます）。作ったファイルや設定はそのまま残ります。
  • アンインストール：Windows の設定→アプリ→インストールされているアプリ→デジタル板書→アンインストール。作った .board ファイルは消えません。
